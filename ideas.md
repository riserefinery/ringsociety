# Ring Society — Reference Preservation Design Direction

## Ground-Truth Specification

The downloaded Figma Make implementation is the visual and interaction authority for Ring Society. The work will preserve its existing white-paper ground, forest-green accents, cream surfaces, Archivo-led typography, serif editorial display treatment, rounded editorial cards, image-led article layouts, scroll reveal behavior, and established responsive composition. No alternate visual direction will be introduced during the CMS vertical slice.

## Style Decisions

The CMS must adapt to the current site rather than reshape it. Editorial data will enter existing cards, resource filters, article body patterns, header, footer, and responsive media surfaces through narrow adapter layers. Existing image assets remain in place until an editor replaces an explicitly CMS-controlled editorial image. Decorative media, motion rules, component geometry, brand colors, spacing, and typography remain code-owned unless a demonstrated editorial requirement calls for a controlled field.

The initial implementation will not introduce new generated imagery because the request is to preserve an established Figma-derived visual system. Any new visual asset for the Contact page will be proposed only after the required content and page intent are confirmed.
